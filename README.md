### Hi, I'm Leo Kwan

I build things and I'm honest about what breaks.

Most of my recent work is AI tooling at [@firstbitelabsllc](https://github.com/firstbitelabsllc) — small, local-first tools for the problems AI coding actually creates:

- 🔁 [**Shadow**](https://github.com/firstbitelabsllc/shadow) — your AI agents keep losing work when a session dies. Shadow gives them one durable plan, atomic claims, and proof before anything is called done. Git, Bash, Python. No daemon, no cloud.
- 📚 [**Claudux**](https://github.com/firstbitelabsllc/claudux) — docs that update when the code changes, using your own Claude/Codex CLI, without touching the sections you wrote yourself.
- 📦 [**Skillbox**](https://github.com/firstbitelabsllc/skillbox) — one reviewed SKILL.md source, mounted across Claude Code, Codex, and Cursor without copying.
- 🛫 [**Takeoff**](https://github.com/leojkwan/takeoff) — turns a release claim into a deterministic local proof pass.

Longer ago: iOS apps and Swift libraries, a music journal called Muse (my first App Store app), and a running-10k page that raised money for charity. Some of it still works.
